# Inteligencia Artificial · Repositorio académico

**Universidad Nacional Mayor de San Marcos — Ingeniería de Sistemas**

Repositorio público de investigaciones, presentaciones y ejemplos de un curso de Inteligencia Artificial. El contenido se organiza por semana siguiendo los temas del sílabo proporcionado; el material académico se incorpora progresivamente.

**Sitio web (una vez habilitado GitHub Pages):** https://jeanhg.github.io/inteligencia-artificial-unmsm/

## Contenido

- `index.html` — portal web y catálogo de semanas.
- `assets/` — estilos y lógica de navegación.
- `data/semanas.json` — catálogo editable de temas, proyectos y recursos publicados.
- `semanas/semana-01/` … `semanas/semana-16/` — páginas y fichas semanales.
- `docs/GUIA_PUBLICACION.md` — instrucciones para incorporar y publicar entregables.

### Cómo se publica cada semana

Cada página reserva un espacio para **informe**, **presentación** y **ejemplo/prototipo**. Los enlaces no aparecen como disponibles hasta que los archivos se hayan subido y sus rutas se hayan registrado en `data/semanas.json`.

La semana 01 incluye la referencia al proyecto **CONTRAIDEA**. No se presupone que el PDF, PowerPoint o código estén subidos.

## Activar la web con GitHub Pages

1. Entra a **Settings → Pages** en este repositorio.
2. En **Build and deployment**, elige **Deploy from a branch**.
3. Selecciona la rama `main` y la carpeta `/(root)`; guarda los cambios.
4. Al publicarse, visita https://jeanhg.github.io/inteligencia-artificial-unmsm/.

Consulta [la guía de publicación](docs/GUIA_PUBLICACION.md) para subir materiales, activar enlaces y comprobar la página.

## Carácter académico

Repositorio estudiantil no oficial; no representa ni está administrado por la Universidad Nacional Mayor de San Marcos. Las semanas y los temas son una organización académica de referencia; la publicación de entregables dependerá de los trabajos efectivamente realizados.
